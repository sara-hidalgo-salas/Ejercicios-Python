# Ejercicios y Fundamentos Avanzados en Python

Repositorio con la resolución de 40 ejercicios prácticos pertenecientes a la **Práctica 0** de la asignatura **Sistemas de Información Empresariales Avanzados** (Grado en Ingeniería Informática, UCLM).

---

## Bloques Temáticos Incluidos

El conjunto de ejercicios abarca desde la sintaxis base hasta conceptos avanzados de arquitectura de software en Python:

* **1. Tipos de Datos y Operaciones Básicas:** Manipulación de variables, operadores aritméticos, booleanos y formateo de cadenas Unicode/multilínea.
* **2. Estructuras de Datos y Colecciones:** Trabajo profundo con listas (slicing, mutabilidad), tuplas e indexación en diccionarios.
* **3. Control de Flujo:** Sentencias condicionales (`if/elif/else`), iteraciones (`while/for`), control de bucles e interacción por consola.
* **4. Funciones y Parámetros Variables:** Creación de funciones con retorno múltiple y manejo de `*args`.
* **5. Programación Orientada a Objetos (POO):** Jerarquías de clases (`Persona` -> `Empleado` -> `Jefe`), encapsulamiento de atributos privados y lógica de estado (clase `Contador`).
* **6. Programación Funcional y Comprensión:**
  * Uso de punteros a funciones y lambdas.
  * Funciones de orden superior: `map()`, `filter()` y `reduce()`.
  * Comprensión de listas y funciones generadoras con `yield`.
* **7. Manejo de Excepciones:** Control de errores comunes (`IndexError`, `KeyError`, `ValueError`, `SystemExit`).
* **8. Módulos y Paquetes:** Estructuración de código modular, uso de `if __name__ == '__main__':` y creación de paquetes con `__init__.py`.
* **9. Entrada/Salida, Ficheros y Expresiones Regulares:**
  * Paso y lectura de argumentos por línea de comandos (`sys.argv`).
  * Lectura y procesamiento de archivos `.txt`.
  * Búsqueda e identificación de patrones complejos utilizando el módulo `re`.
